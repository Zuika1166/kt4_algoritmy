# КТ №4 Алгоритмы

## Требования

- JDK 21
- Maven 3.9+

## Тесты

Запуск всех тестов:

```bash
mvn test
```

## Сборка

```bash
mvn package
```

После сборки классы находятся в `target/classes`.

## Задача 1. Суммы значений по уровням бинарного дерева

Класс:

```text
com.example.kt4.Task1LevelSums
```

В первой строке вводится `n`. В следующих `n` строках задаются `value left right` для вершины с соответствующим индексом.

Запуск:

```bash
java -cp target/classes com.example.kt4.Task1LevelSums
```

Пример:

```text
Ввод:
5
1 1 2
2 3 4
3 -1 -1
4 -1 -1
5 -1 -1

Вывод:
1 5 9
```

Используется обход дерева по уровням.

Сложность:

```text
Время: O(n)
Память: O(n)
```

Для сумм используется `long`.

## Задача 2. K самых частых различных чисел

Класс:

```text
com.example.kt4.Task2TopKFrequent
```

В первой строке вводятся `n` и `k`. Во второй строке вводятся `n` чисел.

Запуск:

```bash
java -cp target/classes com.example.kt4.Task2TopKFrequent
```

Пример:

```text
Ввод:
7 3
4 4 1 1 2 2 3

Вывод:
1 2 4
```

Сначала подсчитываются частоты, затем различные числа сортируются по убыванию частоты и по возрастанию значения при равных частотах.

Сложность:

```text
Время: O(n + d log d)
Память: O(d)
```

`d` — количество различных чисел.

## Задача 3. Медиана потока

Класс:

```text
com.example.kt4.Task3RunningMedian
```

В первой строке вводится `n`. Во второй строке вводятся числа в порядке поступления.

Запуск:

```bash
java -cp target/classes com.example.kt4.Task3RunningMedian
```

Пример:

```text
Ввод:
4
5 2 10 4

Вывод:
5.0 3.5 5.0 4.5
```

Используются две очереди с приоритетом.

Сложность:

```text
Время: O(n log n)
Память: O(n)
```

Медиана хранится в удвоенном виде, поэтому вывод `.0` и `.5` выполняется без ошибок округления.

## Задача 4. Максимальная стоимость маршрута в бинарном дереве

Класс:

```text
com.example.kt4.Task4MaxPathSum
```

В первой строке вводится `n`. В следующих `n` строках задаются `value left right`.

Запуск:

```bash
java -cp target/classes com.example.kt4.Task4MaxPathSum
```

Пример:

```text
Ввод:
5
-10 1 2
9 -1 -1
20 3 4
15 -1 -1
7 -1 -1

Вывод:
42
```

Дерево обрабатывается итеративно в обратном порядке обхода. Рекурсия не используется, поэтому глубокое дерево до 200000 вершин не приводит к переполнению стека.

Сложность:

```text
Время: O(n)
Память: O(n)
```

Для стоимости маршрута используется `long`.

## Задача 5. K-я наименьшая сумма пары

Класс:

```text
com.example.kt4.Task5KthPairSum
```

В первой строке вводятся `n`, `m` и `k`. Во второй строке вводится массив `A`, в третьей — массив `B`.

Запуск:

```bash
java -cp target/classes com.example.kt4.Task5KthPairSum
```

Пример:

```text
Ввод:
3 3 5
1 7 11
2 4 6

Вывод:
11
```

Одинаковые суммы от разных пар учитываются отдельно. Используется min-heap, содержащий следующие кандидаты из отсортированных строк матрицы попарных сумм.

Сложность:

```text
Время: O(k log min(n, k))
Память: O(min(n, k))
```

Массивы при необходимости меняются ролями так, чтобы размер очереди был меньше.

## Задача 6. Медиана скользящего окна

Класс:

```text
com.example.kt4.Task6SlidingMedian
```

В первой строке вводятся `n` и `k`. Во второй строке вводятся `n` чисел.

Запуск:

```bash
java -cp target/classes com.example.kt4.Task6SlidingMedian
```

Пример:

```text
Ввод:
8 3
1 3 -1 -3 5 3 6 7

Вывод:
1.0 -1.0 -1.0 3.0 5.0 6.0
```

Окно хранится в двух упорядоченных мультимножествах. Поддерживаются добавление, удаление и получение центральных элементов.

Сложность:

```text
Время: O(n log k)
Память: O(k)
```
